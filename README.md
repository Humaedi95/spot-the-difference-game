**Twin Scenes** — a spot-the-difference game. Two pictures, nearly identical:
a sunny harbor, a moonlit garden, a cozy bakery. Each hides seven differences —
a missing seagull, a flag that changed colour, a cat that wandered off. Click a
difference to mark it on both pictures, beat the clock, and bank the leftover
seconds as bonus points. Three hand-drawn canvas scenes, hints that pulse,
a timer you can feel, and WebAudio chimes — no images, no libraries, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or serve `game/` with any
static server and open `index.html`. Click a difference to mark it, `H` for a
hint, `M` for sound, `R` to restart. `?shot=title|level1-mid|level2-mid|win`
opens a frozen staging state (used for the screenshots).
